# 95-03 — Fault-injection harness (OPEN)

## goal
Prove the recovery paths still work after any refactor, without waiting for a
real Chrome crash.

## action
Drive `scrape_green` helpers against fakes:
- a page stub whose `evaluate` raises `ConnectionClosed` on the first N calls →
  assert `_safe_js` returns a result and a new handle within 3 attempts;
- a browser stub with no live tabs → assert `_reacquire_page` retries 3x and
  returns a handle (or raises after exhausting, never hangs);
- a page whose DOM has no delivery modal → assert `_ensure_delivery_slot`
  returns `no_slot_found` and performs **zero** clicks;
- a modal tree with 8 filter modals → assert none is treated as delivery.

## acceptance_criteria
- [ ] each stage has a test that fails if its recovery is removed
- [ ] no test needs a real Chrome or network
- [ ] suite runs in the plain venv (no python-telegram-bot)
