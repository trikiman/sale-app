# 96-02 — Aggregation and daily check

## action
`GET /api/admin/green-uptime?hours=168` (`X-Admin-Token`) returns
`backend/green_uptime.summarize()`: verdict, cycles, uptime %, gap incidents
(>45 min without a successful cycle), false zeros (success with zero products and
no legitimate `source_empty`), `last_ok_age_minutes`, `hours_recorded`.

Verdicts: `no_data` / `insufficient` (<24 h or <10 cycles) / `healthy` /
`incident`. `scripts/green_soak_check.py` runs daily at 09:00 (cron
`894c7424bbbe`) and appends one line to `96-SOAK.md`.

## acceptance
- [x] endpoint with window parameter
- [x] false zero and gap incidents defined narrowly (a legitimately empty store is
  not an incident)
- [x] `insufficient` prevents a few clean hours being reported as a healthy week
- [x] daily check script + cron
