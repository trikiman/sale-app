# 97-01 — Pinned URnetwork inbound

## action
`vless/config_gen.build_xray_config` gains an inbound `urn-socks-in` on
`XRAY_URN_LISTEN_PORT` (10809) plus a **pinned** routing rule
`inboundTag=[urn-socks-in] -> outboundTag=urn-ru-0`, inserted before the
balancer rule. The inbound exists only when a UR outbound is present, so the
no-cache invariants of the existing VLESS suite are unchanged.

## why membership is not priority
`urn-ru-0` was already a member of the `leastPing` balancer, and Xray still
selected dead VLESS nodes. A balancer entry is a candidate, not a preference.
